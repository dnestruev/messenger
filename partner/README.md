# Как стать партнёром мессенджера

Партнёр отдаёт сети свой бесплатный проект Supabase. На нём хранятся **зашифрованные** копии
сообщений и фото. Чем больше партнёров, тем больше места и трафика у всей сети.

**Что видит партнёр:** только зашифрованные куски с именами-хешами. Прочитать их нельзя:
ключи есть только у участников чатов. Подменить тоже нельзя: приложение сверяет каждый кусок
с хешем и подписью отправителя, а на узел, который отдаёт подделку, автоматически уходит жалоба.

Понадобится 10 минут и аккаунт GitHub. Денег не нужно.

---

## 1. Создайте проект

1. Зайдите на **supabase.com** и войдите через GitHub.
2. **New project**: любое имя, нажмите **Generate a password**, регион **Europe**.
3. Подождите пару минут, пока проект создаётся.

## 2. Подготовьте базу

1. Слева **SQL Editor** → **+** (новая вкладка).
2. Вставьте **весь** файл [`node.sql`](node.sql) и нажмите **Run**. Должно быть «Success».

## 3. Поставьте функцию узла

1. Слева **Edge Functions** → **Deploy a new function** → **Via Editor**.
2. Удалите пример кода и вставьте **весь** файл [`functions/node/index.ts`](functions/node/index.ts).
3. Внизу в **Function name** впишите **node** и нажмите **Deploy function**.
4. Откройте вкладку **Settings** этой функции и **выключите Verify JWT**, затем **Save changes**.
   Это нужно, потому что вход проверяет центр мессенджера, а не ваш проект.

## 4. Подключитесь к сети

1. Скопируйте адрес проекта: **Project Overview**, строка вида `https://xxxxxxxxxxxxxxxxxxxx.supabase.co`.
2. В мессенджере: ⚙️ → **Сеть** → **Стать партнёром** → вставьте адрес → **Проверить и отправить заявку**.
3. Когда создатель подтвердит узел, он появится в сети со статусом «в сети».

---

## Вопросы

**Сколько места займёт?** Бесплатный проект даёт 1 ГБ под файлы и 5 ГБ трафика в месяц.
На одного человека узел принимает не больше 150 МБ в сутки, чтобы его не забили мусором.

**Что будет, если мой проект уснёт?** Бесплатные проекты засыпают после 7 дней без активности.
Каждый кусок лежит минимум на двух узлах, так что сеть продолжит работать. Разбудить проект
можно кнопкой **Restore** в панели Supabase.

**Как выйти из сети?** ⚙️ → **Сеть** → значок корзины рядом с вашим узлом. Или просто удалите проект.
