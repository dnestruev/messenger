# Мессенджер на GitHub Pages + Supabase (бесплатно)

Личные и групповые чаты, фото, настройки профиля, тёмная тема.
Сквозное шифрование сообщений и фото, установка как приложение, push-уведомления.
Вход по email и паролю, сообщения приходят мгновенно и хранятся в базе.
Сайт хранится на GitHub Pages, сообщения и аккаунты в бесплатном тарифе Supabase.
Карта не нужна, всё бесплатно.

Файлы:
- `index.html`: сам мессенджер
- `config.js`: сюда вставить ключи от Supabase
- `schema.sql`: создаёт базу данных (запускается один раз)
- `update-1.sql`: добавляет группы, фото и настройки (запускается один раз, после `schema.sql`)
- `update-2.sql`: сквозное шифрование и push (один раз, после `update-1.sql`; удаляет старые сообщения)
- `update-4.sql`: сеть партнёров — содержимое сообщений и фото хранится на узлах-партнёрах (один раз, после `update-3.sql`)
- `update-5.sql`, `update-6.sql`: исправления безопасности ключей и прав
- `update-7.sql`: награды партнёрам — значки «Партнёр» и «Плюс», рамки, темы, повышенные лимиты, рейтинг (один раз, после `update-5.sql`)
- `update-8.sql`: аватарки-фото и «Избранное» (один раз, после `update-7.sql`)
- `update-9.sql`: «был(а) в сети …» и приватность (один раз, после `update-8.sql`)
- `update-10.sql`: реакции на сообщения, эмодзи зашифрован (один раз, после `update-9.sql`)
- `partner/`: всё для партнёров — инструкция, `node.sql` и функция `node`
- `update-3.sql`: ответы, изменение и удаление сообщений, блокировка, архив, удаление чата и аккаунта, команда и официальные чаты (один раз, после `update-2.sql`)
- `js/main.js` (логика), `js/crypto.js` (шифрование), `css/styles.css` (оформление), `sw.js`, `manifest.webmanifest`, иконки `*.png`: само приложение
- `supabase/functions/push/index.ts`: функция отправки push (вставляется в Supabase, не на GitHub)

## Шаг 1. Supabase (база данных)

1. Зайдите на **supabase.com**, нажмите **Start your project** и войдите через GitHub.
2. Нажмите **New project**. Укажите любое имя и придумайте пароль базы (сохраните его где-нибудь).
   Регион выберите **Central EU (Frankfurt)**. Подождите пару минут, пока проект создаётся.
3. Слева откройте **SQL Editor**, затем **New query**. Скопируйте туда **весь** файл `schema.sql`
   и нажмите **Run**. Должно появиться «Success».
   Затем так же, в новом запросе, выполните **весь** файл `update-1.sql`.
4. Слева **Authentication** → **Sign In / Providers** → **Email**. Выключите **Confirm email**
   и сохраните. Тогда регистрация работает сразу, без письма (бесплатная почта Supabase
   отправляет всего несколько писем в час).
5. Слева **Project Settings** → **API** (или **API Keys**). Скопируйте:
   - **Project URL**, вида `https://abcd1234.supabase.co`
   - **Publishable key** (или **anon public** key)

## Шаг 2. Вставить ключи

Откройте `config.js` в любом текстовом редакторе (подойдёт и Блокнот) и замените две строки:

```js
export const SUPABASE_URL = 'https://abcd1234.supabase.co';
export const SUPABASE_KEY = 'sb_publishable_...';
```

Эти ключи публичные, хранить их на GitHub нормально. Чужие сообщения защищены правилами
в базе: каждый видит только свои переписки.

## Шаг 3. GitHub Pages (сайт)

1. На **github.com** нажмите **+** → **New repository**. Назовите, например, `messenger`,
   выберите **Public** и нажмите **Create repository**.
2. На странице репозитория нажмите **uploading an existing file**
   (или **Add file → Upload files**), перетащите `index.html`, `config.js`, `schema.sql`, `README.md`
   и нажмите **Commit changes**.
3. Откройте **Settings** → **Pages**. В **Source** выберите **Deploy from a branch**,
   ветку **main**, папку **/ (root)**, затем **Save**.
4. Через 1–2 минуты там появится адрес вида `https://ВАШ-НИК.github.io/messenger/`.

## Шаг 4. Связать сайт и Supabase

В Supabase откройте **Authentication** → **URL Configuration**, в **Site URL** вставьте адрес
сайта из шага 3.4 и сохраните.

## Готово

Откройте сайт, зарегистрируйтесь (ник, email, пароль). Друг регистрируется так же.
Потом впишите его ник в поиск слева и пишите.

## Если что-то не работает

- **«Почти готово, откройте config.js»**: ключи не вставлены или файл не загрузился на GitHub.
- **«Нет связи с сервером»**: неверный URL в `config.js` или Supabase недоступен из вашей сети.
- **Сообщения доходят только после обновления страницы**: проверьте, что `schema.sql`
  выполнился полностью (последняя строка включает мгновенную доставку).
- **После изменения файлов сайт не обновился**: подождите минуту и обновите страницу с Ctrl+F5.

## Ограничения бесплатного тарифа

- **500 МБ базы**: это сотни тысяч текстовых сообщений.
- **1 ГБ под фото**: фото сжимаются примерно до 200–400 КБ, это несколько тысяч снимков.
- **5 ГБ трафика в месяц**: каждый просмотр фото расходует трафик. Это основное ограничение,
  если друзья активно шлют картинки.
- **50 000 пользователей в месяц**: с большим запасом.
- Проект **засыпает после 7 дней без активности**. Включается кнопкой **Restore**
  в панели Supabase, данные не пропадают.

Расход видно в Supabase: **Project Settings → Usage**.

## Шифрование: как это устроено

- У каждого пользователя своя пара ключей (ECDH P-256). Секретный ключ хранится только на устройстве.
  На сервере лежит его копия, зашифрованная **секретным кодом** (PBKDF2, 600 000 итераций + AES-256-GCM).
- У каждого чата свой ключ AES-256-GCM. Он зашифрован отдельно для каждого участника.
- Сообщения и фото шифруются в браузере. Сервер хранит только шифр.
- **Код безопасности** (нажмите на заголовок личного чата): сравните с другом, и вы будете уверены,
  что ключи никто не подменил.
- Если у собеседника сменился ключ, в чате появится предупреждение. Ключ чата ему не отдаётся,
  пока вы не нажмёте «Доверять».

Ограничения, о которых стоит знать:
- Сервер видит, **кто** кому пишет и **когда** (но не что).
- Ключ чата не меняется со временем (в Signal ключи меняются каждое сообщение).
- Код приложения грузится с GitHub. Включите на GitHub двухфакторную защиту, чтобы никто не подменил код.

## Push-уведомления: настройка (один раз)

1. Supabase → **Edge Functions** → **Deploy a new function** → **Via Editor**.
   Имя: `push`. Вставьте весь файл `supabase/functions/push/index.ts`, нажмите **Deploy**.
2. В настройках функции выключите **Verify JWT** (Enforce JWT verification).
   Это безопасно: функция отправляет уведомление только для настоящего нового сообщения и только один раз.
3. Edge Functions → **Secrets**: добавьте три секрета из файла `push-secrets.txt`
   (`VAPID_PUBLIC_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT`). **Этот файл не загружайте на GitHub.**
4. **Database → Webhooks** → включите и создайте вебхук: таблица `messages`, событие **Insert**,
   тип **Supabase Edge Functions**, функция `push`, метод POST.
5. В приложении: ⚙️ → включите **Push-уведомления**.
   На iPhone сначала «Поделиться» → «На экран Домой», затем откройте приложение с иконки.

## Команда и официальные чаты

- Создатель (значок «Создатель») назначает тестеров: ⚙️ → **Команда** → ник → «Сделать тестером».
- Значок нельзя поставить себе самому: это проверяет база.
- Создатель может сделать любую свою группу **официальной** (откройте группу → нажмите на заголовок).
  Официальный чат с галочкой закреплён сверху, писать в него может только команда.
- Добавить ещё одного создателя можно только через SQL Editor:
  `update public.profiles set role = 'creator' where username = 'ник';`

## Сеть партнёров

Партнёры подключают свои бесплатные проекты Supabase как узлы хранения. Инструкция — в `partner/README.md`.

- Центр (этот проект) хранит аккаунты, ключи и короткие указатели на сообщения.
- Зашифрованное содержимое сообщений и фото лежит на узлах, в двух копиях.
- Имя каждого куска — его хеш, а каждое сообщение подписано отправителем: узел не может прочитать,
  подменить или подделать данные. Подмену приложение замечает и автоматически жалуется на узел;
  после жалоб от трёх разных людей за сутки узел отключается.
- Узлы включает и отключает создатель: ⚙️ → **Сеть партнёров**.
- Пока узлов нет, всё хранится в центре, как раньше.

### Награды партнёрам

Базовый мессенджер бесплатный и полный у всех. Партнёры получают сверху:

- значок **Партнёр** у ника (виден всем);
- фото до 2560 px и альбомы до 10 фото;
- до 100 групп и до 500 человек в группе (у остальных 20 групп и 100 человек);
- свой цвет акцента, темы «Бумага» и «Неон», рамки аватарки;
- место в рейтинге «Лучшие партнёры» (1 очко за каждое хранимое сообщение и 50 за каждый день без перерыва);
- можно подарить **Плюс** (те же награды) 5 друзьям.

Центр сам проверяет каждый узел раз в 10 минут. Если узел не отвечает 30 минут, награды у партнёра и его друзей
пропадают, пока узел не вернётся (счёт дней начинается заново). Назвать себя партнёром без работающего узла нельзя.
