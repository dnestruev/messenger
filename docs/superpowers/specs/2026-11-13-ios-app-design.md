# Приложение для iPhone (TrollStore) — короткий дизайн

**Зачем:** на iOS 15 (iPhone 7) Safari не даёт уведомлений. Нужно приложение, которое ставится через TrollStore и уведомляет о новых сообщениях, когда свёрнуто. Патчи сайта (десятки в день) должны прилетать сразу, без переустановки.

**Цели:** иконка → внутри живой сайт https://dnestruev.github.io/messenger/ без адресной строки; уведомления в фоне; микрофон/камера для звонков. **Не цели (пока):** звонок «как обычный» при заблокированном экране (CallKit), Android/ПК, App Store. **Анти-цели:** ломать сайт или звонки; секреты в репозитории.

## Подходы
1. Обёртка (WKWebView) с живым сайтом + свой фон — **выбрано**: обновления мгновенные, код сайта не трогается.
2. Переписать на Swift — отвергнуто владельцем: каждый патч = новый .ipa.
3. Отдельный клиент только для уведомлений — неудобно, переписка всё равно в Safari.

Уведомления (решение владельца «оба способа»): Swift-часть в фоне сама опрашивает сервер и показывает «Новое сообщение от @ник» (ключи шифрования ей недоступны); если сайтовая часть ещё не уснула, она подменяет уведомление на текст (тот же идентификатор `c-<чат>`).

## Как устроено (мои решения)
- Фон: беззвучный звук по кругу (UIBackgroundModes audio, mixWithOthers) — не даёт iOS усыпить приложение; включается только когда свёрнуто.
- Опрос раз в 20 с: RPC `app_poll(секрет)` → по чатам «от кого, сколько». Секрет устройства выдаёт `app_register()` вошедшему человеку, хранится у приложения; в базе — только sha256. Не нужен JWT, токены сайта не трогаем (у Supabase они одноразово обновляются — две стороны с одним токеном выкинули бы человека из аккаунта).
- `app_poll` повторяет фильтры push: не свои, не от заблокированных, не скрытые копии стикеров (их шлёт сам человек, значит отсекаются «не свои»).
- База: `update-24.sql` (таблица `app_devices`, `app_register`, `app_unregister`, `app_poll`) — в рабочую только после «применяй update-24».
- Сайт: если есть `window.webkit.messageHandlers.native` — регистрирует устройство, передаёт секрет; при скрытой странице на новое сообщение шлёт `notify` с расшифрованным текстом; на выход — `device: null`.
- Сборка: GitHub Actions (macos), `swiftc` без Xcode-проекта, подпись `ldid` с entitlements, `.ipa` в релизе `ios-latest`. iOS 15.0+.

## Оставлено исполнителю
Иконка (своя, точка-логотип), тексты разрешений, обработка ссылок наружу (Safari).
