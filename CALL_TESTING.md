# Тест звонков: звук и демонстрация

Базовая версия: `299509d937c053195f32173578ca6350c566e888`.


Эксперимент публикуется в main по явному запросу владельца.
После публикации функций тестовый режим включается только параметром `?calltest=1`.
Обычная ссылка без параметра отключает новые инструменты после перезагрузки.
Для аудиозвонков с демонстрацией звонящий должен открыть тестовую ссылку;
для двусторонней демонстрации её открывают оба участника.

## Функции

- Моно-звук, ограничение исходящего аудио 48 кбит/с (если браузер поддерживает).
- Переключение шумоподавления/автогромкости; подавление эха остаётся включённым.
- Оценка качества по WebRTC stats и снижение нагрузки видео при устойчивом ухудшении.
- Экран вместо камеры; голос остаётся. Запрос разрешения всегда через браузер.
- Передача экрана с ПК, просмотр на телефоне. Захват системного звука не добавлен.
- Возврат камеры или аудиозвонка при остановке, освобождение захвата при завершении.

## Проверка

`node --test tests/unit/*.mjs` — 16 тестов.
Синтаксис модулей: `node --input-type=module --check < js/main.js`.
Реальные браузерные звонки, захват экрана и вёрстка на устройствах НЕ проверены:
Chromium в текущем окружении не запускается (socket: Operation not permitted).

Перед публикацией проверить два разных аккаунта: ПК→телефон, телефон→ПК,
аудио→экран→аудио, камера→экран→камера, отмену выбора, системную остановку,
завершение во время выбора, экран при выключенном микрофоне.
Проверить 320×568, 375×667, 667×375, 1440×900.

## Откат

Сначала отключить тестовый режим: убрать `calltest=1` из адреса и перезагрузить оба клиента.
Полный откат — отдельным revert-коммитом изменений этого эксперимента, затем
`sh scripts/bump.sh` и публикация. Не сбрасывать main принудительно: более поздние
исправления звонков должны сохраниться. База данных этим обновлением не меняется.

## Текущий блокер

Вызов между разными аккаунтами приходит, но соединение после ответа не установлено.
TURN пока не настроен. Нужна диагностика ICE/SDP и параметры авторизованного TURN-сервиса.
Эксперимент не решает отсутствие маршрута между сетями.
