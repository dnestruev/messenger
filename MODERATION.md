# Роли модерации — update-18

## Активация в рабочей базе

В Supabase → SQL Editor выполнить по порядку:
1. `update-18.sql` — таблица назначений и проверки прав сервером.
2. `scripts/assign-moderators.sql` — назначить @skitle модератором, @peteroxhka старшим на 30 минут.

Скрипт ищет только точные usernames. Если одного из них нет, транзакция отменяется целиком.
Повторный запуск не продлевает срок и не перезаписывает существующее назначение.
После выполнения таблица результата показывает роли и время окончания.
Отсчёт начинается при выполнении второго файла. Затем пользователям открыть настройки заново.

## Права

| Действие | Модератор | Старший | Создатель |
| --- | --- | --- | --- |
| Пользователи, статистика, бан и разбан нижестоящих | Да | Да | Да |
| Назначение/снятие модератора и тестера у нижестоящих | Нет | Да | Да |
| Назначение/снятие старшего | Нет | Нет | Да |
| Настройка ссылки и текста поддержки проекта | Нет | Да | Да |
| Выдача значков, узлы, TURN и остальные функции владельца | Нет | Нет | Да |

Собственную роль менять нельзя. Создателя нельзя изменить или забанить.
Личная переписка и ключи шифрования модераторам не раскрываются.
Удаление чужих сообщений и муты не добавлены этим обновлением.

Прежнее profiles.role не меняется при временной выдаче модерации: после expires_at сервер
сразу перестаёт признавать временное назначение, остаётся исходная роль (например, тестер).
Не нужны открытый браузер, расписание ChatGPT или периодическое удаление строк.
Истёкшая строка остаётся для истории и идемпотентности стартового скрипта.

## Проверки

24 проверки прав/истечения срока выполнены на PostgreSQL через PGlite.
Миграция проверена с повторным применением; браузерная вёрстка не проверена в этом окружении.
Команда:
```
npm install --prefix /tmp/roles-test @electric-sql/pglite
PGLITE_MODULE=/tmp/roles-test/node_modules/@electric-sql/pglite/dist/index.js node tests/unit/moderation.mjs
```

Для срочного снятия выданных ролей (SQL Editor):
```sql
delete from public.moderation_roles
where user_id in (select id from public.profiles where username in ('skitle', 'peteroxhka'));
```
Это не затрагивает прежние роли, аккаунты и переписки.
